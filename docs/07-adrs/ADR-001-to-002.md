# ADR-001: Frontend Framework & Bespoke Design System
- **Status**: ACCEPTED
- **Context**: The frontend requires a high-performance, real-time command dashboard with animated waveforms, live map tracking, and block inspection. Generic UI kits (Bootstrap, basic Tailwind templates) fail to convey the security and clinical sophistication expected in a market-ready prototype.
- **Decision**: Adopt **React 19 + Vite** paired with a **Bespoke Vanilla CSS Design System** (`tokens.css`).
- **Consequences**:
  - Eliminates dependency on heavy component libraries.
  - Gives 100% fine-grained control over glowing cyber-clinical aesthetics, CSS keyframe animations, and backdrop filters.
  - Guarantees fast Hot Module Replacement (HMR) and sub-second production bundle builds.

# ADR-002: Backend Gateway & Python Simulation Architecture
- **Status**: ACCEPTED
- **Context**: The project presentation requires a multi-threaded Python simulation engine with Web3.py. We need an API layer that bridges the simulation threads with the frontend web clients over REST and WebSockets.
- **Decision**: Implement a unified **FastAPI** (Python 3.13) service that directly hosts the simulation worker pool, cryptographic signer nodes, Web3.py RPC client, and WebSocket broadcaster.
- **Consequences**:
  - Eliminates inter-process latency between simulator and API.
  - Provides native async performance for high-throughput WebSocket streaming.
  - Automatically produces interactive Swagger/OpenAPI documentation.
